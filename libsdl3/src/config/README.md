# SDL_build_config generation maps

`SDL_build_config.h` is generated by the build2 `autoconf` module from
upstream `include/build_config/SDL_build_config.h.cmake` (cmake flavor).

Each `subs-*.build` file defines `config_subs`, a list of
`NAME@true|false|value` pairs applied as `autoconf.substitutions` for that
`$c.target.class`. No static `SDL_build_config_<platform>.h` is copied into
the build.

| File | Source of the map |
|------|-------------------|
| `subs-macos.build` | CMake-generated config on macOS (SDL 3.4.12) |
| `subs-windows.build` | Upstream `SDL_build_config_windows.h` |
| `subs-linux.build` | Posix/macOS HAVE_* baseline + typical Linux drivers |

Regenerate maps when upgrading upstream if configure results change
materially. Prefer expanding real project checks under
`build/autoconf/checks/` over hard-coding new `HAVE_*` entries when a
capability can be expressed with static platform macros.
